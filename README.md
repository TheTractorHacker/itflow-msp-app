# ITFlow MSP — Android App

Native Android app for ITFlow MSP. Built with Kotlin + Jetpack Compose + Material 3.

> Not affiliated with or endorsed by ITFlow LLC.

## Setup

1. Clone the repo and open in Android Studio
2. Add your `google-services.json` to `app/`
3. Run the app — enter your server URL on first launch

## Requirements
- Android Studio Hedgehog or newer
- Android SDK 35
- Your ITFlow server running v2.4.12+
- `google-services.json` from your Firebase project (`itflow-msp`)
